 decimal number delineators

Certain  Java interpreters configured for languages other than English,
 Spanish for example use Commas vs Periods to define the decimal number delineator.
Commas are not compatible with Rinearn software

Solution :
 Launch the interpreter with a command that forces it to load the English format:

java "-Duser.language=en" "-Duser.country=US" -jar .JAVA_HL3D_33%Me-Mi_Vmxb_Vsplt_14May26.jar

Known Bugs JA_IFAvg2csv_varMXB_intLogo_11Jan2501.jar 12 May 2025 
The Version 2.8 release of IF_average allows for the saving of Background Correction Files. 
These do not conform to the format for saved Data Files. 
THUS : 
The current software version : JA_IFAvg2csv_varMXB_intLogo_11Jan2501.jar 
Will not properly exclude these and hang the process. 
Please Move Any Background Correction Files to another Folder before Processing. 

Also be aware : 
IF_average : a Folder for Saving Files must be Pre-Defined. 
Failure to do so, upon attempting to save Multiple Files will cause AirSpy SDR# to crash
